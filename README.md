# Caderno de Caixa

Demonstração interativa de um painel financeiro em português, com lançamentos fictícios. O projeto roda inteiramente no navegador.

## Como testar

Abra `index.html` no navegador. Selecione março ou abril, adicione uma receita ou despesa e acompanhe a atualização do saldo, do orçamento e do gráfico por categoria. Use **Restaurar exemplo** para voltar aos dados iniciais do mês selecionado.

## Tecnologias

HTML, CSS responsivo e JavaScript puro. As alterações ficam em memória até a página ser recarregada. O exemplo funciona offline, sem cadastro ou dependências externas.
